# CLAIM_STATUS

FiveText uses the following claim-status system:

- DOCUMENTED_IN_REPOSITORY — supported by documents included in the repository.
- AUTHOR_TESTIMONY — stated by the author as direct testimony.
- PATTERN_HYPOTHESIS — proposed connection between events.
- SYMBOLIC_FLAG — metaphysical or literary marker used for navigation.
- CONTRADICTED_NODE — node weakened or contradicted by later events.
- UNRESOLVED_NODE — open node requiring future observation.
- LEGAL_REQUEST_FOR_INVESTIGATION — request for competent authorities to examine facts.
