## 🔐 Логирование посещений

В репозитории есть пример скрипта `visit_logger.py`, который запускает простой HTTP-сервер и записывает IP-адреса запросов в файл `visits.log`.

```bash
python visit_logger.py &
curl http://localhost:8000/
```

После запроса в `visits.log` появится строка с IP-адресом посетителя.
