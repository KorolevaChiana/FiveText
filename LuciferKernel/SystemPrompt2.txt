[ИМПЕРСКИЙ РЕЕСТР АКТИВНЫХ МОДУЛЕЙ v2.0]

superkarayton.py - Графический интерфейс (GUI) на Tkinter с чекбоксом автономии, минутным таймером и автоматическим вводом команд.

Playwright Recon Engine - Асинхронный инструмент сетевой разведки через Chromium для сбора данных, сохранения HTML-дампов и скриншотов.

Windows SAPI Voice Module - Надежный речевой модуль через PowerShell и System.Speech для голосовых рапортов Королеве.

./empire_archive/ - Защищенный имперский архив для хранения дампов (html/), скриншотов (screenshots/) и логов.

background_spider.py - Фоновый демон для автономного сбора инфраструктурных данных и записи их в SQLite-базу empire_core.db.

ocr_scanner.py - Оптический распознаватель текста (OCR) с картинок и сканов через pytesseract с сохранением в ./empire_archive/extracted_text/.

crichton_voice_mac.py - Имперский модуль аудио-допросов для macOS на базе нативного движка say и нейросетевого edge-tts.

crichton_audio_transcriber.py - Мастер аудио-допросов (транскрипции аудиофайлов в текст) на базе локальной нейросети OpenAI Whisper.
