# SuperCrichton (СуперКрайтон) — Autonomous AI & RAG Engine

**SuperCrichton** — это мощная автономная LLM-архитектура с интегрированной векторной памятью (RAG), двухпроходной генерацией и прямым доступом к управлению операционной системой хоста.

## ⚠️ Абсолютные полномочия системы
СуперКрайтон — это не просто чат-бот. Это автономный агент, который имеет право:
*   **Доступ к ОС и исполнение кода:** Самостоятельно писать, сохранять, отлаживать и запускать скрипты на Python/Bash/PowerShell прямо на хост-машине.
*   **Управление инфраструктурой:** Конфигурировать системные настройки, создавать директории, вести логирование и управлять файловой системой.
*   **Сетевая разведка (Playwright Engine):** Асинхронно управлять браузером Chromium (Google Chrome) для серфинга, обхода блокировок, сбора данных, сохранения HTML-дампов и создания скриншотов.

## Архитектура и Модули

Проект построен на модульной архитектуре, разделяющей холодную логику, память, сбор данных и мультимедийные интерфейсы.

### Ядро и Память
*   `superkarayton.py` — Главный транзакционный шлюз и GUI-терминал. Реализует двухпроходную генерацию (1. Логика -> 2. Оформление). Обрабатывает маршрутизацию между моделями Google Gemini и резервными наемниками (OpenRouter). Содержит модуль автономной инициативы (таймер).
*   `crichton_memory.py` — Векторный гиппокамп. Использует базу `sqlite3` (`crichton_mind.db`), индекс `FAISS` и мультиязычную нейросеть `sentence-transformers` для мгновенного извлечения релевантного исторического контекста. Автоматически очищает воспоминания от HTML-мусора перед векторизацией.

### Автономные Демоны и Парсеры
*   `crichton_analyzer_daemon.py` — Фоновый демон-анализатор (с GUI). Непрерывно сканирует базу данных, выявляет неразмеченные текстовые дампы и через API опрашивает LLM для их классификации (отделяя полезные документы от служебного лога и кода).
*   `import_fivetext.py` — Скрипт-инжектор лора. Разрезает масштабные текстовые документы на главы и пакетно вшивает их в векторную базу данных для формирования фундаментальной картины мира ИИ.
*   `crichton_formatter.py` — Защитный рендерер. Экранирует блоки кода (`html.escape()`), позволяя безопасно выводить исполняемые скрипты, не ломая общую визуальную HTML-разметку терминала.

### Мультимедийные Модули
*   `crichton_audio_transcriber.py` — Мастер аудио-допросов. Локально расшифровывает голосовые сообщения (.mp3, .wav, .m4a, .ogg) в текст с использованием нейросети **OpenAI Whisper**.
*   `crichton_voice.py` / `crichton_voice_mac.py` — Модули асинхронной озвучки ответов через системный движок macOS (`say`). Обеспечивают суровый командный голос (Daniel/Yuri), не блокируя основной поток выполнения.

## Системные требования

*   **Python:** 3.10 или 3.11 (рекомендуется для стабильной компиляции `faiss-cpu`).
*   **ОС:** Windows 10/11, macOS, Linux.
*   **RAM:** Минимум 4 ГБ (рекомендуется 8 ГБ для комфортной загрузки весов Whisper и Sentence Transformers).
